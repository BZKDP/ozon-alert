# Ozon Alert

Десктоп-уведомлятор о новых заказах Ozon Express для продавца (Windows).

## Что это

Фоновая программа на Python: следит за кабинетом Ozon Seller и при появлении
нового заказа (в первую очередь RealFBS Express с коротким окном сборки)
поднимает на весь экран красное окно с сиреной — номер заказа, что собрать,
склад и сколько минут до отгрузки. Сирена звучит, пока не нажата кнопка «ПРИНЯЛ».
Зависимостей нет — только стандартная библиотека Python (tkinter, winsound).

## Как работает

Каждые ~20 секунд опрашивает Ozon Seller API `POST /v3/posting/fbs/list`
за последние несколько часов, отсекает уже показанные заказы через `seen.json`
и на новых подходящих по статусу/признаку Express показывает алерт. Журнал
пишется в `ozon_alert.log` с ротацией.

## Настройка

Скопируйте `.env.example` в `.env` и впишите ключи из кабинета Ozon:

    OZON_CLIENT_ID=...
    OZON_API_KEY=...

Параметры опроса (`POLL_SECONDS`, `LOOKBACK_HOURS`, `EXPRESS_ONLY` и др.)
меняются в блоке «НАСТРОЙКИ» в начале `ozon_alert.py`.

## Запуск

    python ozon_alert.py                обычный режим (фон)
    python ozon_alert.py --test         демо-окно, проверить сирену и всплытие
    python ozon_alert.py --express-only  реагировать только на Express
    python ozon_alert.py --reset        забыть известные заказы (seen.json)

## Автозапуск (Windows)

`run_hidden.vbs` запускает программу через `pythonw.exe` без окна консоли.
Положите ярлык на него в папку автозагрузки (`Win+R` → `shell:startup`)
или заведите задачу в Планировщике заданий — программа будет стартовать
при входе в систему. Для отладки есть `.bat`-файлы с видимой консолью.
